# 文档索引

这个目录是仓库的知识库。组织方式遵循“逐步展开”：先从这里看，再打开当前
任务真正需要的文档。

## 核心文档

- `DEVELOPMENT_STANDARD.md` - 开发前必须遵守的文档标准

## 执行计划

- `exec-plans/_template.md` - 新需求先复制这个模板
- `exec-plans/active/` - 正在实现的计划
- `exec-plans/completed/` - 已交付或已关闭的计划

## 维护规则

- 文档保持简洁，并用链接串起来。
- 不把所有内容塞进一个大文档；复杂内容拆成聚焦的小文档。
- 行为变化时，在同一次改动里更新相关文档。
- 任务完成后，把计划从 `active/` 移到 `completed/`，并补充最终验证记录。
